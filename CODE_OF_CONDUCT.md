# Code of conduct

DataRanger follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, keep criticism about the work and not the
person, and make the project a place where anyone can ask a question or send a first pull request.
Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or
any other project space.

## Reporting

If something here makes you uncomfortable, report it privately through this repository's
**Security** tab, using **Report a vulnerability**, and start the title with "Conduct:". Only the
maintainer can see these reports. Every report is read and answered, and kept confidential.

The maintainer may remove comments, commits or other contributions that break this code, and may
block someone who keeps doing so.
